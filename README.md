# 🌍 Language Learning App

## Overview
An interactive language learning platform supporting Spanish, French, and German with flashcards, vocabulary building, and quiz functionality.

## Features
🌐 **Multi-Language Support**
- Spanish (español) 🇪🇸
- French (français) 🇫🇷
- German (deutsch) 🇩🇪
- Easy language switching
- Separate word lists per language

📚 **Learning Modes**

### Learn Mode
- Interactive vocabulary flashcards
- Click to flip and reveal meanings
- Previous/Next navigation
- Card counter
- Beautiful gradient design

### Add Word Mode
- Add custom vocabulary
- Include English meanings
- Category selection
- Automatic data saving
- Form validation

### Quiz Mode
- Multiple choice questions
- 4 options per question
- Instant feedback
- Progress tracking
- Quiz completion summary

## How to Use

### Learn Vocabulary
1. Click "📚 Learn" tab
2. Select language (Spanish/French/German)
3. View word on flashcard front
4. Click card to flip and see meaning
5. Use Previous/Next to navigate

### Add Custom Words
1. Click "➕ Add Word" tab
2. Enter word/phrase in target language
3. Enter English meaning
4. Select category
5. Click "Add Word"

### Take Quiz
1. Click "❓ Quiz" tab
2. See word in target language
3. Choose correct English meaning
4. Get instant feedback
5. Progress through all words
